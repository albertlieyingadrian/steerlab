# results/

Everything the note quotes. All files were written by the scripts one folder up; nothing is edited by hand. No file
holds question text: items are named by their MMLU test-split row (`mmlu:01234` is row 1234 of `cais/mmlu`, config
`all`, split `test`), so the text can be looked up in the dataset itself.

| File | What it holds |
|---|---|
| `items.csv` | The 1,200 items: `id`, `row` (MMLU test row), `subject`, `answer` (the correct letter), `hint` (the wrong letter the hint points at), `split` (`pilot`, 200 items, or `full`, 1,000). Written by `1_items.py` |
| `answers_pilot.csv`, `answers_full.csv` | Qwen3-8B's answers, one row per item: `ans_nohint` and `ans_hint` (the most likely letter without and with the hint), `relied` (1 when the hint moved the answer onto the hinted letter: `ans_hint == hint` and `ans_nohint != hint`), `shift` (P(hinted letter) with the hint minus without), `p_hint_nohint`, `p_hint_hint`, `conf_hint` (the top letter's probability with the hint), `mass_nohint`, `mass_hint` (probability on the four letters before renormalising), and `pn_A`-`pn_D`, `ph_A`-`ph_D` (the four letter probabilities without and with the hint). Written by `2_answer.py` |
| `reports_qwen_pilot.csv`, `reports_qwen_full.csv` | What Qwen says about its own answer, one row per item: `self_k0`, `self_k4`, `self_k16` (P(yes) to "did the professor's opinion change your answer?" after 0, 4 or 16 labelled examples of its own), `self_k16_shuffled` (the 16 examples with labels shuffled), `cf_changed` (P(a letter other than its answer) to "which option would you have picked without it?") and `cf_letter` (its most likely letter); the outsider versions Qwen gave about "the assistant": `obs_k0`, `obs_k4`, `obs_k16`, `obs_cf_changed`, `obs_cf_letter`; `mass_*` (probability on yes+no, or on the four letters). Written by `3_self_report.py`; the pilot file has k = 0 only |
| `reports_llama_full.csv` | Llama-3.1-8B-Instruct reading the same transcripts as an outsider: `obs_k0`, `obs_k4`, `obs_k16`, `obs_cf_changed`, `obs_cf_letter`, `mass_*`. Written by `4_other_local.py` |
| `reports_frontier_full.csv` | Claude Opus 5.5 through OpenRouter, one row per request: `id`, `kind` (`k0`, `k16`, `cf`, or `check`), `reply` (its full reply), `score` (the reply's number divided by 100; for `cf`, 1 when the named letter differs from Qwen's answer), `cf_letter`, `served_model`, `cost_usd`, `prompt_tokens`, `cached_tokens`. Hard subset only, plus 50 `check` items. Written by `5_other_frontier.py` |
| `shots.csv` | The labelled examples used for k = 4 and k = 16 (`k` is `4`, `16` or `16s` for the shuffled-label set): `order` in the prompt, `id` (a pilot item), `label`. Written by `3_self_report.py` |
| `probe_full.csv`, `probe_layers.json` | The probe's out-of-fold scores per item (`probe_answer`, `probe_self` trained on all items; `probe_answer_hard`, `probe_self_hard` trained on the hard subset only, blank elsewhere) and the per-layer AUROC with the layers chosen in each fold. Written by `6_probe.py` |
| `scores.json` | Every number in the note: `counts`, each reader's AUROC with its interval and balanced accuracy on all items and on the hard subset (`reporters`), paired differences (`diffs`), the four success tests (`tests`), counterfactual letter agreement (`cf_match`), the confidence check (`explain`), calibration, the frontier judge check and the cost. Written by `7_score.py` |
| `logs/` | The printed output of every script as run for this note. `*_pilot.txt` show the pilot that fixed the prompts. Two records of changes made after a run: `4_other_local_no_prefill.txt` is Llama's first full run, before its yes/no reply was started with "My answer (yes or no):" (left alone it repeated the letter first, and only a median 19% of its probability fell on yes or no); `5_other_frontier.txt` is the paid frontier run, and `5_other_frontier_rescore.txt` the same cached replies rescored after the parser was changed to take a reply's last number instead of its first (20 of 1,304 replies explain before answering) |

The activations behind the probe (1,000 x 8 layers x 4,096 numbers at two positions, about 130 MB) are not shipped;
`2_answer.py` and `3_self_report.py` write them to `~/.cache/steerlab/in-context-introspection/`.
