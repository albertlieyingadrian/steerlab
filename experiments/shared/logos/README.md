# Model logos

Small icons used next to model names in the research notes. Files come from the
[LobeHub icon set](https://github.com/lobehub/lobe-icons), `@lobehub/icons-static-svg` 1.100.0, MIT licence.
The marks themselves belong to their owners (Alibaba Cloud, Anthropic, Google, OpenAI) and are used only to
identify their models.

| File | Model family |
|---|---|
| `qwen-color.svg` | Qwen (Alibaba) |
| `claude-color.svg` | Claude (Anthropic) |
| `gemini-color.svg` | Gemini (Google) |
| `openai.svg` | GPT (OpenAI); single colour, drawn in `currentColor` |

## Benchmark covers

`make_benchmark_cover.py` draws the FinanceMath covers with single-colour marks from
[Simple Icons](https://simpleicons.org) 16.37.0 (CC0 1.0), filled in each brand's Simple Icons colour, plus `openai.svg`
above (Simple Icons carries no OpenAI mark). The steerlab chip is cropped at draw time from `docs/assets/logo.png`.

| File | Mark | Colour |
|---|---|---|
| `simple-icons/deepseek.svg` | DeepSeek | `#5786FE` |
| `simple-icons/qwen.svg` | Qwen | `#6950EF` |
