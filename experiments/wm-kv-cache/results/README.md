# Results

Every file the note's numbers come from. Field-by-field descriptions are in the experiment's
[README](../README.md#data): `ckpt_s{1,2,3}.pt` (trained weights and training logs), `ckpt_untrained_s1.pt` and
`eval_untrained_s1.json` (the dream-mode floor), `eval_s{1,2,3}.json` (per-seed evaluation: policy sweep, timing,
attention, probes, causal eviction), `summary.json` (every number and interval in the note), `figures_printout.txt`
(every number the figures plot) and `gpu_ledger.jsonl` (Modal GPU time and cost per job).
