## `validate`

```python signature
validate(backend, prompt, nodes, *, metric, counterfactual=None, groups=None, singles=True, steer_scale=3.0,
         n_controls=20, seed=0, rules=None, thresholds=None, progress=None) -> Report
```

<ParamField path="backend" type="InterventionBackend" required>
  `TracerBackend(model)` for circuit-tracer, `toy.demo()` for the toy model, or anything with `tokens`, `logits`,
  `active_features`, `decoder_norm`, `token_id` and `describe`.
</ParamField>
<ParamField path="prompt" type="str" required>The prompt (or a name registered with `TracerBackend.register`).</ParamField>
<ParamField path="nodes" type="Sequence[FeatureNode]" required>The features under test: `layer`, `pos`, `feature`, `activation`.</ParamField>
<ParamField path="metric" type="Metric" required>`logit_diff`, `logprob`, `logit`, or `Metric(name, fn)`.</ParamField>
<ParamField path="counterfactual" type="str">A prompt with a different answer, for the patch test. Positions are aligned from the end.</ParamField>
<ParamField path="groups" type="Sequence[GroupSpec]">Defaults to all nodes together, then each alone (`singles=True`).</ParamField>
<ParamField path="rules" type="Mapping[(layer, feature), str | callable]">Explanation rules for the swap test.</ParamField>
<ParamField path="progress" type="Callable[[str], None]">Called with a line per group.</ParamField>

<ResponseField name="Report" type="object">
  <Expandable title="fields">
    <ResponseField name="groups" type="list[GroupResult]">Per group: `ablation`, `steering`, `patch`, `explanation_swap`, `verdict`, `reasons`.</ResponseField>
    <ResponseField name="clean_metric, counterfactual_metric, scale" type="float" />
    <ResponseField name="thresholds, n_controls, seed, backend, notes" type="..." />
  </Expandable>
</ResponseField>

Each `CheckResult` holds `metric`, `effect`, `normalized` (|effect| / scale), `kl` and `controls`. `controls` maps
`random` and `matched_norm` to `ControlStats`: the control effects, their mean and spread, and the empirical
`p_value`.

## `decide(ablation, steering, patch, thresholds)`

The verdict rules on their own, returning `(Verdict, reasons)`. Use it to re-apply the rules to stored results with
different thresholds.

## Metrics

| Function | Value |
|---|---|
| `logit_diff(target, contrast)` | logit(target) - logit(contrast) |
| `logprob(target)` | log p(target) |
| `logit(target)` | logit(target) |
| `kl(p_logits, q_logits)` | mean KL(p ‖ q) over positions |

## Toy backend

`circuitkit.validate.toy.demo()` is a linear model with a planted switch (`SWITCH`), two readouts (`READOUTS`), a
redundant pair (`BACKUP`) and 40 noise features. `demo_nodes(backend)` gives the five planted features as a graph
would. Use it for tests.
