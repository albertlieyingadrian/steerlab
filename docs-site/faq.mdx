---
title: "FAQ"
description: "Common questions."
---

<AccordionGroup>
  <Accordion title="Do I need a GPU?">
    Only to build graphs or run the validator on a real model. The diff runs on saved summaries, the validator has a
    toy backend, and labels need only an API key, or none with a cache.
  </Accordion>
  <Accordion title="Which models and transcoders work?">
    Anything circuit-tracer supports: Gemma-2, Gemma-3, Llama-3.2, Qwen3, per-layer transcoders and cross-layer
    transcoders. `TracerBackend` uses only `ReplacementModel`'s public methods.
  </Accordion>
  <Accordion title="Why does the diff call so many features 'up' or 'down'?">
    Training reweights many features a little, and a feature whose influence rises on all 8 prompts is a real change
    even after correction. For the claim "this is the circuit training added", look at the control contrast
    (`specific`), replication, and then the validator.
  </Accordion>
  <Accordion title="Why is my validator verdict 'readout' when ablation clearly moves the metric?">
    Check the p-values in the reasons. If matched-norm controls move the metric as much, the effect is not specific
    to these features, and the verdict is `nonspecific`. If the effect is under 20% of the scale, it does not count
    as necessary. Check also that `n_controls` is at least 19.
  </Accordion>
  <Accordion title="How much do labels cost?">
    With Claude Haiku 5.5 ($0.10 / $0.50 per million tokens), explaining and scoring one feature with detection and
    simulation costs about half a cent. The 50-feature Gemma run, with Neuronpedia's labels scored too, cost $0.26.
  </Accordion>
  <Accordion title="Can I use my own explainer?">
    Yes. Anything with a `model` and `usage` attribute and `complete(system, prompt, max_tokens) -> str` works.
    `ScriptedLLM` wraps a plain function.
  </Accordion>
  <Accordion title="Is circuitkit part of circuit-tracer?">
    No. It is an independent package in the steerlab repo that builds on circuit-tracer's public API. Fixes found
    while building it went upstream (for example decoderesearch/circuit-tracer#129).
  </Accordion>
</AccordionGroup>
