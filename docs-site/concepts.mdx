## Features and units

circuit-tracer replaces each MLP with a **transcoder**, a wide sparse layer whose units are **features**. A graph node
is a feature at one token position: `(layer, position, feature)`. circuitkit's diff works with **units**,
`"layer:feature"`, by summing a feature's influence over the positions where it fired. That makes graphs of different
models on the same prompt comparable.

## Influence

A graph's adjacency matrix gives the direct effect of each node on each other node and on the target logit.
**Influence** is the total effect along all paths to the target (circuit-tracer's `compute_node_influence`). The
**replacement score** and **completeness score** say how much of that flow goes through features rather than through
error nodes (the part of each MLP the transcoder does not reconstruct).

## Switch or readout

A feature can be highly influential in the graph and still not matter to the model:

- a **switch** is necessary: switch it off and the behaviour goes away. It is also specific: random features of the
  same size do not do the same.
- a **readout** is active wherever the behaviour is, and the graph routes influence through it, but intervening on it
  does nothing beyond controls. It reads the behaviour, it does not cause it.

Both of steerlab's circuits episodes found readouts where the graph pointed. The [validator](/guides/validate) makes
that check routine.

## Controls and nulls

| Tool | Comparison | Why |
|---|---|---|
| validate | Random features at the same layer and position | Rules out "any change to the residual stream at that spot does it" |
| validate | Features matched by write size, \|activation\| x decoder norm | Rules out "it matters only because it writes a lot" |
| diff | Random swaps of before/after within prompt pairs | Rules out graph-to-graph noise |
| diff | A control training run that did not learn the behaviour | Rules out changes that any training causes |
| diff | Another seed | Checks that the change replicates |

## Reconstruction error (FVU)

The fraction of variance unexplained: the squared error of the transcoder's reconstruction of an MLP's output, divided
by that output's variance, per layer. 0 is perfect. The transcoders were trained on the base model, so after
fine-tuning FVU may rise. If it does, graphs of the fine-tuned model describe it less faithfully, and the diff warns.

## Labels and their scores

A label is a hypothesis about where a feature fires. **Detection** tests it as a classifier: does the label let a
model tell activating excerpts from silent ones? **Simulation** tests it token by token. **Calibration** asks whether
the explainer's confidence means anything. On Gemma-2-2B it barely does.
