---
title: "Install"
description: "circuitkit is light by default. Add circuit-tracer for real models and a provider SDK for labels."
---

circuitkit needs Python 3.11 or newer. The base install pulls in only numpy, pydantic and typer.

<Tabs>
  <Tab title="pip">
    ```bash install
    pip install "steerlab-circuitkit @ git+https://github.com/albertlieyingadrian/steerlab#subdirectory=packages/circuitkit"
    ```
  </Tab>
  <Tab title="uv">
    ```bash install
    uv pip install "steerlab-circuitkit @ git+https://github.com/albertlieyingadrian/steerlab#subdirectory=packages/circuitkit"
    ```
  </Tab>
  <Tab title="From a clone">
    ```bash install
    git clone https://github.com/albertlieyingadrian/steerlab && cd steerlab
    pip install -e packages/circuitkit
    ```
  </Tab>
</Tabs>

## Optional extras

<CodeGroup>
```bash Real models install
# circuit-tracer is not on PyPI; install it from GitHub (it brings torch and TransformerLens)
pip install "git+https://github.com/decoderesearch/circuit-tracer"
```

```bash Claude labels install
pip install "steerlab-circuitkit[anthropic] @ git+https://github.com/albertlieyingadrian/steerlab#subdirectory=packages/circuitkit"
export ANTHROPIC_API_KEY=...   # read by the Anthropic SDK; circuitkit never prints it
```

```bash OpenAI labels install
pip install "steerlab-circuitkit[openai] @ git+https://github.com/albertlieyingadrian/steerlab#subdirectory=packages/circuitkit"
export OPENAI_API_KEY=...
```
</CodeGroup>

## Check it works

```bash
circuitkit version
circuitkit validate --demo
```

You should see six groups with their verdicts: one `switch` group of all five features, one `switch`, two
`readout`s and two `backup`s.

<Tip>
  The example data (graphs, cached label replies, notebooks) lives in `packages/circuitkit/examples/` in the steerlab
  repo, not in the wheel. Clone the repo to run the quickstart's diff and labels steps.
</Tip>
